Положи сюда файлы с ЛЮБЫМИ именами — пути в коде прописывать не нужно.

media/
  ava/         — аватар (png, jpg, jpeg, webp, gif, avif). Если несколько — берётся первый по алфавиту.
  video/       — фоновые ролики (mp4, webm, mov, m4v). Все файлы, shuffle при каждом заходе.
  audio/       — музыка (mp3, ogg, wav, m4a, flac, aac). Все файлы, shuffle при каждом заходе.
  background/  — картинка фона экрана загрузки. Если несколько — случайная при заходе.

После добавления/удаления файлов пересобери сайт (trunk serve сам обновит manifest перед сборкой).
